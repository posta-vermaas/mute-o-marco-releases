# Mute-o-Marco: downloads

Mute-o-Marco is een klein Mac-appje van Posta Vermaas. Je kiest tracks uit je Pro Tools-sessie en elke track krijgt twee knoppen: **Mute** en **Solo**, met de klikregels van Pro Tools. Deze repo bevat alleen de builds; de code staat in een privé-repo.

## Installeren

1. Download de nieuwste `Mute-o-Marco-….zip` onder [Releases](https://github.com/posta-vermaas/mute-o-marco-releases/releases).
2. Pak hem uit en sleep **Mute-o-Marco** naar Programma's.
3. De app is niet genotariseerd, dus de eerste keer moet je hem toestaan:
   - **macOS 15 of nieuwer:** dubbelklik de app, klik op Gereed, open Systeeminstellingen › Privacy en beveiliging en klik bij Mute-o-Marco op **Open toch**.
   - **macOS 14:** rechtermuisklik op de app › Open › Open.

Daarna werkt hij zichzelf bij via **Mute-o-Marco › Zoek naar updates…**.

Nodig: macOS 14 of nieuwer (Apple Silicon of Intel) en Pro Tools met een open sessie.
